# D-001 启动资本方案决策

## Problem
需要先落地一个“可运行”的初版，而不是只停留在规范文档。

## Options
1. 只保留协议文档，不创建示例项目。
2. 创建 demo 项目与两条初始任务，立即可跑流程。

## Tradeoff
- 方案 1：成本低，但无法验证可执行性。
- 方案 2：成本中等，但可立即验证并形成自迭代输入。

## Decision
选择方案 2，先用 demo 项目沉淀启动资本。

## Validation Plan
- 初始化 `projects/demo` 全部文件。
- 将 `T-001` 设为 READY，供任一 Agent 立即领取。
- 准备 `T-002` 作为下一轮协议自迭代入口。
